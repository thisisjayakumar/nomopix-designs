📋 DEPLOYMENT ORDER
═══════════════════
1. Database (MySQL) → 2. Backend (API) → 3. Frontend (React)

───────────────────────────────────────────────────────────────────────

🗄️  STEP 1: SETUP MYSQL DATABASE (5 min)
═══════════════════════════════════════════

Option A: Railway (Recommended)
  → Go to: https://railway.app
  → New Project → Provision MySQL
  → Copy connection details
  → Run: mysql -h HOST -u USER -p DATABASE < server/db.sql

Option B: PlanetScale
  → Go to: https://planetscale.com
  → Create database → Get connection string

───────────────────────────────────────────────────────────────────────

🖥️  STEP 2: DEPLOY BACKEND (5 min)
══════════════════════════════════

Platform: Render.com (Free tier)
  → Go to: https://render.com
  → New + → Web Service
  → Connect GitHub → Select repo
  
  Settings:
  ┌─────────────────────────────────────┐
  │ Name: nomopix-backend               │
  │ Environment: Node                   │
  │ Build: npm install                  │
  │ Start: npm start                    │
  └─────────────────────────────────────┘

  Environment Variables:
  ┌─────────────────────────────────────┐
  │ DB_HOST=your_mysql_host             │
  │ DB_USER=your_mysql_user             │
  │ DB_PASSWORD=your_mysql_password     │
  │ DB_NAME=nomopix_db                  │
  │ JWT_SECRET=random_32_char_string    │
  │ PORT=5000                           │
  │ WHATSAPP_NUMBER=917010066299        │
  │ ADMIN_EMAIL=nomopix.designs@gmail  │
  │ NODE_ENV=production                 │
  └─────────────────────────────────────┘

  Test: https://your-backend.onrender.com/api/health

───────────────────────────────────────────────────────────────────────

🌐 STEP 3: DEPLOY FRONTEND (3 min)
═══════════════════════════════════

A) UPDATE BACKEND URL:
   Edit: client/.env.production
   ┌─────────────────────────────────────────────────────────┐
   │ REACT_APP_API_URL=https://your-backend.onrender.com    │
   └─────────────────────────────────────────────────────────┘

B) DEPLOY TO NETLIFY:

   Method 1: Drag & Drop (Fastest)
   ┌────────────────────────────────────┐
   │ 1. cd client && npm run build      │
   │ 2. Go to: https://app.netlify.com │
   │ 3. Drag 'client/build' folder     │
   │ 4. Done! ✅                        │
   └────────────────────────────────────┘

   Method 2: GitHub Auto-Deploy (Best)
   ┌────────────────────────────────────────────┐
   │ 1. Push to GitHub                          │
   │ 2. Netlify → Import from Git               │
   │ 3. Base: client                            │
   │ 4. Build: npm run build                    │
   │ 5. Publish: client/build                   │
   │ 6. Add env: REACT_APP_API_URL=...          │
   └────────────────────────────────────────────┘

🐛 COMMON ISSUES
════════════════

Issue: API calls failing
Fix:   Check CORS in server/index.js
       Verify REACT_APP_API_URL

Issue: 404 on page refresh
Fix:   Check _redirects file exists
       in client/public/

Issue: Database connection error
Fix:   Verify all DB credentials
       in Render environment variables
